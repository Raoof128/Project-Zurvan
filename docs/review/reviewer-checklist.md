# Reviewer Checklist

When inspecting reports, follow these steps via the local Workbench UI:

1. **Check Citations**: Verify mapped citations cover all claims.
2. **Check Warnings**: Address missing evidence sections flagged by the templating engine.
3. **Verify Redaction**: Ensure paths and secrets are hidden.
4. **Export Format**: Pick Markdown or JSON.
5. **Share**: Safely move the output to your destination.
