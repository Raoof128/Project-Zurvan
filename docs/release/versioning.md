# Versioning

Zurvan tracks its own version and active features locally.

## Check Version

Run:
```bash
zurvan version
```

This will print:
- Current Zurvan Version
- Python Version
- Project Root Path
- A checklist of currently enabled Major Features (like CLI Memory, Graph Lite, MCP Server, etc.)

## Health Checks
If something isn't working, check the system health:
```bash
zurvan doctor
```

This checks all required directories, files, databases, and safety configurations.
