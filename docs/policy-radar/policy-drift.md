# Policy Drift

As multiple federated projects evolve, their core rules and policies may drift apart. The Policy Drift tool analyzes coverage to help you maintain consistency.

## Drift Detection

A drift occurs when a specific policy category is detected in at least one project but is completely missing in another. This highlights a rule that might have been forgotten or intentionally skipped.

## Commands

```bash
zurvan project radar policies
zurvan project radar drift
```
