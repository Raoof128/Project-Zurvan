# Evidence Packs Overview

Evidence Packs are shareable, citation-backed bundles of knowledge created from your federated local projects. They aggregate search results, graph context, decisions, claims, and policy radar pings into a unified artifact.

## Why Evidence Packs?

When you need to make a project decision, draft a report, or explain a technical context, you need evidence. Evidence Packs automate the gathering of this context safely, without relying on cloud synchronization, LLMs, or external APIs. 

## Key Guarantees

- **Local First**: Everything is built locally.
- **Redaction by Default**: Absolute paths, emails, and secrets are redacted automatically.
- **Immutable Raw Data**: Raw project sources are never read directly by default and never included.
- **No Path Leaks**: Packs are saved to `~/.zurvan/evidence-packs/` to prevent accidental commits.
