# Recommended Obsidian Plugins

Zurvan **does not require any plugins**. However, these plugins greatly enhance the experience.

## 1. Dataview
Allows querying the knowledge base using SQL-like syntax. Perfect for listing open decisions or tracking claim confidence.

## 2. Templater
Zurvan provides templates in `wiki/templates/`. Templater makes it easy to apply these when creating new claims, decisions, or concepts.

## 3. Advanced Tables
Helps format markdown tables in your evaluation metrics or logs.

## 4. Tag Wrangler
Makes it easy to rename tags across the entire knowledge base (e.g., from `#bug` to `#issue`).

## 5. Excalidraw
For drawing architectural diagrams directly inside Obsidian, saved as Markdown-compatible files.
