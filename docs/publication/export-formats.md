# Publication Export Formats

Zurvan supports the following local export formats via `zurvan publish export <id> --format <format>`:

- **markdown**: Clean, readable raw markdown files with citation mapping.
- **json**: Machine-readable format containing the report, audit stats, and citations.
- **html**: A dependency-free, printable web view using local CSS.
- **pdf/docx**: (Planned) Gracefully falls back if local dependencies aren't met.
